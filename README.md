# 땅따먹기 퀴즈 배틀

교실 TV용 조별 대항 땅따먹기 퀴즈. 교사가 노트북으로 모든 조작을 하고, 학생은 말로 답한다.

## 실행
- `index.html`을 더블클릭해 브라우저(크롬·엣지)로 연다. 인터넷 연결이 필요 없다.
- `F` 키 또는 [전체화면] 버튼으로 전체화면 전환.

## 규칙
1. 설정: 조 수(2~6), 조 이름, 문제 세트(여러 개 선택 시 섞어서 출제), 보드 크기(소 5×4 / 중 6×5 / 대 8×5), 문제 시간(없음/15/20/30초), 게임 길이, 스틸 켜기/끄기.
2. 차례인 조가 칸을 고른다.
   - 빈 땅: 어디든 선택 가능. 난이도 1~2 문제.
   - 다른 조 땅: 우리 땅과 상하좌우로 맞닿은 칸만 공격 가능(점선 테두리와 ⚔ 표시). 난이도 3 문제.
   - 해당 난이도 문제가 떨어지면 다른 난이도에서, 모두 쓰면 처음부터 다시 섞어 낸다.
3. 정답이면 그 칸을 차지, 오답이면 변화 없음. 어느 쪽이든 다음 조 차례.
4. 특수 칸(빈 칸의 약 20%, 숨겨져 있음, 정답으로 차지했을 때만 발동)
   - 🔁 한 번 더: 같은 조가 한 번 더.
   - 🎁 보너스 땅: 맞닿은 빈 땅 하나를 덤으로 차지(없으면 효과 없음).
   - 💥 지진: 맞닿은 다른 조 땅 하나가 빈 땅이 됨(요새는 제외, 없으면 효과 없음).
   - 🏰 요새: 이 칸은 이후 공격받지 않음.
5. 빈 땅이 없어지거나, 게임 길이가 다 되거나, [게임 종료]를 누르면 끝.
   점수 = 차지한 칸 수 + 가장 큰 연결 땅(상하좌우로 이어진 덩어리) 칸 수.

## 스틸(가로채기)
- 각 조는 한 판에 스틸권 1장을 가진다(점수판의 번개: 노랑 = 남음, 회색 = 사용함).
- 오답(X) 판정 직후 스틸권이 남은 다른 조가 있으면 "스틸 기회!"가 뜬다. 조 버튼 또는 숫자키 1~6으로 고르고, [스틸 없음] 또는 Esc로 건너뛴다.
- 조를 고르는 순간 그 조의 스틸권이 쓰인다(맞히든 틀리든). 같은 문제로 O/X를 다시 판정한다. 스틸 판정 중 Esc는 스틸 실패로 처리한다.
- 스틸 정답이면 그 칸을 스틸한 조가 차지한다(맞닿음 조건·난이도와 무관, 공격 문제였으면 그 칸을 빼앗음). 특수 칸 효과도 그대로 발동한다.
- 한 문제에 스틸은 1번. 스틸이 끝나면 차례는 원래 순서대로(원래 차례였던 조의 다음 조)로 넘어간다.
- 스틸로 "한 번 더" 칸을 얻어도 스틸한 조에게 추가 턴을 주지 않는다(차례 순서가 헷갈리지 않게).
- [정답 보기]로 답을 공개한 뒤 오답 처리하면 스틸 기회는 없다.
- 문제 시간이 켜져 있으면 스틸 조를 고른 뒤 시간을 다시 잰다.
- 되돌리기(Z)는 스틸권 사용까지 함께 되돌린다.

## 게임 길이
- 제한 없음 / 10분 / 15분 / 20분: 위쪽에 남은 시간이 보이고, 문제 창이 떠 있어도 시간이 흐른다. [일시정지](P)로 멈출 수 있다. 마지막 1분은 빨갛게 깜빡인다. 0이 되면 진행 중인 문제(스틸 포함)를 마친 뒤 끝난다.
- 조별 3턴 / 조별 5턴: 위쪽에 "라운드 n/N". 모든 조가 N번씩 차례를 마치면 끝난다. "한 번 더"로 얻은 추가 턴과 스틸은 차례 수에 세지 않는다. 마지막 차례에서 "한 번 더"가 나와도 그 시점에 끝난다.
- 남은 시간·라운드는 이어하기에도 저장된다. 이어하기를 하면 시간은 멈춘 상태로 시작한다.

## 오답 복습
- 결과 화면의 [틀린 문제 복습]: 오답·스틸 실패였던 문제를 한 장씩 크게 본다. ← → 로 넘기고 Space로 정답을 연다. [전체 문제 보기]로 이번 판에 나온 문제 전부를 볼 수 있다.
- 같은 문제가 여러 번 나왔으면 마지막 결과로 보고, 나중에 맞힌 문제는 틀린 문제에서 빠진다. 스틸 성공으로 끝난 문제도 틀린 문제에 넣지 않는다.
- 틀린 문제가 없으면 "전부 정답!"이 표시된다.

## 그림 문제
- 그림이 있는 문항은 문제 아래에 그림이 크게 나온다. 그림을 누르면 화면 가득 커지고, 다시 누르거나 Esc로 닫는다. 그림을 못 불러오면 "그림을 불러올 수 없습니다"가 표시되고 게임은 그대로 진행된다.
- 편집기에서 넣기: 문항의 [그림] 버튼으로 파일을 고르거나, 문제 칸을 누른 상태에서 Ctrl+V로 복사한 그림을 붙여 넣는다. 긴 변 1280px 이하 JPEG로 줄여서 저장한다(투명한 부분은 흰색). [그림 삭제]로 뺀다.
- 그림은 저장 공간을 많이 쓴다. 편집기 위쪽에 사용량(약 5MB까지)이 보이고, 넘치면 경고가 뜬다. 그림이 많으면 내보내기 파일로 보관한다. 내보내기·가져오기 파일에는 그림이 함께 들어간다(가져오기는 30MB까지).
- 메모장으로 넣기: 그림 파일을 `sets/img/` 폴더(없으면 만든다)에 넣고 문항에 `img`를 적는다(index.html 기준 상대 경로).
  ```js
  { q: '이 지도에서 ㉠ 지역은?', a: '도심', level: 2, img: 'sets/img/city-map.png' },
  ```
  그림 주소는 상대 경로나 `data:image/…`만 쓸 수 있다(인터넷 주소 http… 는 무시된다).

## 배경음악
- 직접 만든 짧은 칩튠 3곡: 설정·보드 대기(느긋), 문제 푸는 중(긴장, 문제 시간 5초 이하면 빨라짐), 결과(밝은 팡파르). 효과음보다 작게 나온다.
- [음악 켬/끔]은 [효과음 켬/끔]과 따로 동작하고 설정이 저장된다. 브라우저 정책 때문에 첫 클릭(또는 키 입력) 뒤에 시작하고, 다른 탭으로 가면 멈춘다.

## 단축키
| 키 | 기능 |
|---|---|
| Space | 정답 보기 |
| O | 정답 판정 |
| X | 오답 판정 |
| 1~6 | 스틸할 조 고르기(스틸 기회 때) |
| N | 문제 바꾸기(차례 유지) |
| Esc | 문제 창 닫기(차례 유지) / 스틸 없음 / 그림 크게 보기 닫기 |
| Z | 되돌리기(직전 판정 취소, 여러 번 가능) |
| P | 시간 일시정지·계속(시간제일 때) |
| ← → | 복습 화면에서 넘기기 |
| F | 전체화면 |

문제 편집기 안에서는 게임 단축키가 동작하지 않는다.

한글 입력 상태에서도 작동한다.

## 저장
- 판정할 때마다 브라우저에 자동 저장된다. 창을 닫았다 열어도 설정 화면의 [이어하기]로 계속할 수 있다.
- 브라우저 설정상 저장이 막혀 있으면 저장 없이 진행된다.

## 문제 편집기 (게임 화면에서 문제 만들기)
설정 화면의 [문제 편집]을 누른다.
- 왼쪽: 세트 목록. [새 세트], [세트 복제], [세트 삭제](내가 만든 세트만), [원래대로](고친 기본 세트를 처음 상태로).
- 오른쪽: 세트 제목·설명, 문항 표(문제, 정답, 난이도 ★1~3, 풀이 메모, 그림). ▲▼로 순서 이동, ✕로 삭제.
- 문제나 정답이 빈 문항은 빨간 줄로 표시되고 게임에 나오지 않는다. 문항이 0개인 세트는 설정 화면에서 고를 수 없다.
- 고친 내용은 자동 저장된다(위쪽에 "저장됨" 표시).

여러 문항 붙여넣기: 엑셀·한글 표에서 복사해 붙여 넣는다. 한 줄에 한 문항, 칸 순서는
`문제 → 정답 → 난이도(1~3) → 메모`. 칸 구분은 탭(표 복사 시 자동), 탭이 없으면 `|`.
난이도와 메모는 생략할 수 있고, 난이도가 없거나 1~3이 아니면 2로 들어간다.
```
물가가 계속 오르는 현상은?|인플레이션|1
환율이란?|우리 돈과 외국 돈을 바꾸는 비율||교과서 ○쪽
```

파일로 주고받기:
- [세트 내보내기]: 고른 세트를 `땅따먹기-세트이름.json` 파일로 저장한다.
- [전체 내보내기]: 내가 만든 세트와 고친 기본 세트를 한 파일로 저장한다.
- [가져오기]: 받은 `.json` 파일을 고른다. 내 세트로 추가되며, 같은 제목이 있으면 "제목 (2)"처럼 이름이 붙는다. 형식이 잘못된 파일은 이유를 알려 주고 아무것도 바꾸지 않는다.

편집 내용은 **이 PC의 이 브라우저에만** 저장된다. 다른 선생님께 게임을 줄 때는 내보내기 파일을 함께 보내고, 받는 쪽에서 [가져오기]를 한다. 브라우저 설정상 저장이 막혀 있으면 편집기 위쪽에 경고가 뜨므로, 내보내기 파일로 보관한다.

## 문제 세트 고치기·추가하기 (메모장)
`sets` 폴더의 `.js` 파일을 메모장으로 열어 고친다. 저장할 때 인코딩은 UTF-8.
(문제 편집기에서 기본 세트를 고친 경우, 편집기에서 고친 내용이 이 파일보다 우선한다. [원래대로]를 누르면 파일 내용으로 돌아간다.)

문제 한 줄의 형식:
```js
{ q: '문제', a: '정답', level: 1 },
{ q: '문제', a: '정답', level: 3, note: '정답과 함께 보여 줄 설명' },
```
- `level`: 1(쉬움), 2(보통), 3(어려움). 빈 땅은 1~2, 공격은 3을 낸다.
- 줄 끝 쉼표(`,`)를 지킨다. 마지막 문제 뒤 쉼표는 있어도 된다.
- 글자 안에 `'`를 쓰려면 `\'`로 쓰거나 바깥 따옴표를 `"`로 바꾼다.

새 세트 만들기:
1. 기존 파일(예: `sets/recreation.js`)을 복사해 `sets/my-set.js`로 저장한다.
2. 파일 안의 `id`를 다른 세트와 겹치지 않게 바꾸고(`'my-set'`), `title`, `description`, `questions`를 고친다.
   ```js
   window.QUIZ_SETS = window.QUIZ_SETS || [];
   window.QUIZ_SETS.push({
     id: 'my-set',
     title: '우리 반 퀴즈',
     description: '설명',
     questions: [
       { q: '문제', a: '정답', level: 1 }
     ]
   });
   ```
3. `index.html`을 메모장으로 열어 `<script src="game.js"></script>` 줄 **위에** 다음 줄을 넣는다.
   ```html
   <script src="sets/my-set.js"></script>
   ```

## 파일
- `index.html`, `style.css`, `game.js` — 게임
- `voxel.js` — 복셀 캐릭터와 픽셀 텍스처(블록, 아이콘)를 그리는 스크립트
- `editor.js` — 문제 편집기(붙여넣기·그림·가져오기·내보내기)
- `music.js` — 배경음악(WebAudio 오실레이터)
- `fonts/` — 갈무리11 글꼴(Galmuri11.woff2, Galmuri11-Bold.woff2)과 라이선스 파일
- `sets/*.js` — 문제 세트(사회2 Ⅴ~Ⅷ, 레크리에이션)
- `tests/logic.test.mjs` — 로직 테스트. `node tests/logic.test.mjs`로 실행
